Тут подсказки про теги для подключения CSS и GS

Теги нужны для подключения различных сторонних файлов. Например CSS и GS.

Тег link нужен для того что бы можно было подключить страницу CSS и прописывается он обязательно в шапке, в теге head.

Так же обязательно прописать два атрибута rel (в этом атрибуте мы подключаем страницу стилей stylesheet). И второй атрибут href (нужен для того что бы подключить сам CSS файл). Прокладываем путь до самого файла

Тут будет написано про подключение GS

Тег script можно прописать в head и можно прописать в body. Лучше всего прописывать его в body и в самом низу страницы, что бы не тормозить общую загрузку HTML страницы. Что бы подключить отдельный файл, необходимо внутри открывающегося и закрывающегося тега прописать атрибут src=

Очень важно не перепутать атрибуты. Атрибут href используется только для подключения CSS. В то время как для GS необходим атрибут src

Тут подсказки про теги div и span

Тег div создает определенный блок и к этому блоку можно через css добавить любые стили

Тег span создает строчный тег и к этому тегу так же можно через css добавить стили. (Данный тег можно прописать внутри тега div для выделения определенной области или слова)
